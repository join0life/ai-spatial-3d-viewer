# 준주거지역 건물 변화탐지 결과 3D 시각화 웹 뷰어

> AI-Hub 항공영상 도시건물 변화탐지 데이터의 과거/현재 이미지쌍과 annotation을 기반으로, 준주거지역 내 건물 변화 객체를 Three.js 기반 3D 공간에서 시각화한 프론트엔드 포트폴리오입니다.

## 1. 프로젝트 개요

본 프로젝트는 항공영상 기반 건물 변화탐지 결과를 웹에서 직관적으로 검토할 수 있도록 만든 3D 시각화 뷰어입니다.

AI-Hub 항공영상 도시건물 변화탐지 데이터는 과거 항공영상과 현재 항공영상을 비교하여 변화가 발생한 건물의 polygon annotation을 제공합니다. 본 프로젝트는 이 annotation을 Three.js에서 렌더링 가능한 scene 데이터로 변환하고, 항공영상 plane 위에 변화 객체를 polygon, bounding box, marker, extrusion 형태로 시각화합니다.

## 2. 문제 배경

준주거지역은 주거 기능을 중심으로 일부 상업·업무 기능이 함께 존재할 수 있는 도시 구역입니다. 이러한 지역에서는 신축, 철거, 갱신, 형태 변경과 같은 건물 변화가 발생할 수 있으며, 건물 변화는 지도, 건물 footprint, 건축물대장, GIS 건물정보 등 도시 공간정보 갱신과 연결될 수 있습니다.

실제 행정 영역에서도 항공사진 판독을 통해 전년 대비 변동이 확인된 건축물을 조사하고, 무단 증축이나 무허가 신축·증축 여부를 확인하는 사례가 있습니다.

## 3. 문제 정의

단순 2D 이미지 위 annotation만으로는 다음 정보를 직관적으로 파악하기 어렵습니다.

- 변화 객체의 위치
- 변화 객체의 실제 외곽 형태
- 변화 유형: 신축 / 소멸 / 갱신
- 갱신 세부유형: 층 변화, 구조물 추가, 옥상 색상 변화, 외곽선 변화 등
- 여러 변화 객체 중 시각적으로 우선 확인할 대상

따라서 변화 객체를 3D 공간에서 유형별로 구분하고, polygon, bbox, marker, extrusion 등 다양한 방식으로 탐색할 수 있는 시각화 인터페이스가 필요합니다.

## 4. 프로젝트 목적

본 프로젝트의 목적은 AI-Hub 변화탐지 annotation을 프론트엔드에서 검토 가능한 3D 시각화 데이터로 변환하고, 사용자가 준주거지역 내 건물 변화 객체를 직관적으로 탐색할 수 있는 웹 뷰어를 구현하는 것입니다.

본 프로젝트는 AI 모델 학습이나 변화탐지 알고리즘 구현이 아니라, 이미 제공된 annotation 데이터를 구조화하고 Three.js 기반 3D UI로 시각화하는 것에 초점을 둡니다.

## 5. 데이터 가공

원본 annotation을 그대로 사용하지 않고, 3D 렌더링과 인터랙션에 필요한 형태로 가공했습니다.

| 가공 데이터       | 설명                                      |
| ----------------- | ----------------------------------------- |
| `changeType`      | `polygon.shift`를 신축/소멸/갱신으로 매핑 |
| `updateTypes`     | `polygon.update`를 갱신 세부유형으로 매핑 |
| `bbox`            | polygon을 감싸는 2D 사각형                |
| `center`          | bbox 기준 중심점                          |
| `worldPolygon`    | Three.js 좌표로 변환한 polygon            |
| `worldBBox`       | Three.js 좌표로 변환한 bbox               |
| `visualHeight`    | 3D extrusion 표현용 높이                  |
| `displayPriority` | 화면상 표시 우선순위                      |

`visualHeight`는 실제 건물 높이가 아니라, 변화 유형을 3D 공간에서 구분하기 위한 시각화용 값입니다. AI-Hub annotation에는 실제 건물 높이값이 포함되어 있지 않습니다.

`displayPriority`는 실제 위험도나 행정적 우선순위가 아니라, 변화유형과 갱신유형을 기준으로 화면에서 우선적으로 확인할 객체를 구분하기 위한 UI용 값입니다.
본 프로젝트에서는 신축·소멸 객체를 `high`, 층 변화·구조물 추가·외곽선 변화 객체를 `medium`, 옥상 색상 변화처럼 외형 변화가 상대적으로 작은 갱신 객체를 `low`로 분류했습니다.

```txt
high
- 신축
- 소멸

medium
- 층 변화
- 철골구조 완성
- 설치·구조물 추가
- 외곽선 변화

low
- 옥상 색상 변화
```

## 6. 주요 기능

### Visualization Mode

변화 객체를 네 가지 방식으로 시각화합니다. 각 모드는 한 번에 하나만 선택할 수 있습니다.

- **Polygon**: AI-Hub annotation의 `polygon.points`를 기반으로 변화 건물의 실제 외곽 영역을 표시합니다.
- **Bounding Box**: polygon의 최소/최대 x, y 좌표를 계산해 객체를 감싸는 사각형을 표시합니다.
- **Polygon + Bounding Box**: 실제 변화 영역과 객체 식별 영역을 동시에 표시합니다.
- **Extrusion**: polygon을 위로 돌출시켜 3D 형태로 강조합니다. 실제 건물 높이가 아니라 변화 유형별 시각화용 높이를 사용합니다.

### Marker Toggle

변화 객체의 중심점에 marker를 표시하거나 숨길 수 있습니다. Marker는 현재 선택된 Visualization Mode와 독립적으로 제어됩니다.

### Object Interaction

객체 click 시 선택 상태를 표시하고, 상세 패널에서 변화유형, 갱신유형, 이미지 기준 변화 영역 크기, 표시 우선순위를 확인할 수 있습니다.
